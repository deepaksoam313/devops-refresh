# DevOps Refresh — AWS + GCP

Background: 6 years DevOps experience (AWS, GCP). Goal: intensive one-week refresher covering the DevOps-relevant services of both clouds, hands-on.

## Documents

| File | Contents |
|---|---|
| 01-aws-gcp-service-comparison.md | Full service-by-service mapping and architectural differences |
| 02-one-week-plan.md | 7-day intensive schedule (what to study + lab each day) |
| 03-key-concepts.md | Detailed side-by-side concept notes (IAM, networking, compute, containers, CI/CD, observability, security, IaC) |
| 04-labs.md | Lab instructions per day + free-tier/cost guardrails |

## How to use

1. Read 01 first to rebuild the mental map.
2. Follow 02 day by day; each day's lab is in 04.
3. 03 is the reference you skim the morning of each day and add to as you learn new things.
